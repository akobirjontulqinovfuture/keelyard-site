# keelyard.site

Marketing landing page for [keelyard](https://github.com/akobirjontulqinovfuture/keelyard).

Live: https://akobirjontulqinovfuture.github.io/keelyard-site/

Facts on the page come from the keelyard README. Star counts are fetched live from the GitHub API and omitted if the request fails.

To drop in Montajyor’s promo: put the file at `assets/video/hero.mp4` and set `data-video="assets/video/hero.mp4"` on the `.reel` element in `index.html`.
